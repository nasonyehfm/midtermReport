變更儲存格順序
當您的筆記本包含大量的程式碼儲存格時，您可能會遇到想要變更這些儲存格執行順序的情況。您可以透過選擇要移動的儲存格，並點擊下方螢幕截圖中所示的 UP CELL（上移儲存格）或 DOWN CELL（下移儲存格）按鈕來執行此操作 −

![image](changing_cell_order.jpg）
您可以多次點擊該按鈕以將儲存格移動多個位置。

刪除儲存格
在專案開發過程中，您可能會在筆記本中引入一些現在不需要的儲存格。您只需點擊一下，即可輕鬆地從專案中移除這些儲存格。請點擊程式碼儲存格右上角的三個垂直圓點圖示。

Deleting Cell
點擊 Delete cell（刪除儲存格）選項，目前的儲存格將會被刪除。
